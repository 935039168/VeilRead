# Chrome Reviewer Notes (English)

1. Install in Chrome 116+ and open an ordinary HTTPS page. Browser-internal pages do not permit extension injection.
2. Open the toolbar popup and choose Read Current Page to verify the floating reader and page extraction.
3. Select Edge Panel in the popup, open it again, and verify automatic hiding after the pointer leaves.
4. Choose Open Side Panel and verify that long text scrolls in the browser-native side panel.
5. Open Settings and verify typography, the cool-gray theme, opacity, and all three display modes.
6. Import a TXT file in the library and add an HTTP(S) online-reading URL. Chapter navigation requests only the same website.
7. Press Alt+X to verify emergency hide, then Alt+V to restore intentionally.
