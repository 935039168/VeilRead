# Chrome Web Store 商店文案（简体中文）

## 名称

VeilRead

## 简短说明

轻量、可定制、注重本地隐私的网页与小说阅读器。

## 单一用途

将用户选择的本地文本或网页内容以可定制阅读层呈现。

## 详细说明

VeilRead 让你在当前网页中阅读长文本，也可以导入本地 TXT。它提供自由悬浮窗、贴边面板和浏览器原生侧边栏三种显示方式，支持网页正文提取、用户触发的同站章节阅读、目录、阅读进度、字体、行距、透明度和多种配色。

书籍、设置、站点规则和阅读进度保存在浏览器本地。VeilRead 不提供云同步，不建设数据接收服务器，不包含广告、遥测或第三方分析。
