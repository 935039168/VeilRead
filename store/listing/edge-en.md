# Microsoft Edge Add-ons Listing (English)

## Name

VeilRead

## Short description

A lightweight, customizable, privacy-conscious reader for web pages and novels.

## Single purpose

Present local text or web content selected by the user in a customizable reading layer.

## Detailed description

VeilRead imports local TXT files and extracts readable content from the current page. Choose a floating reader, edge panel, or the browser's native side panel. Adjust same-site chapter navigation, catalogs, local progress, typography, opacity, and color themes.

Books and reading data remain in the browser. The extension has no cloud sync, advertising, telemetry, third-party analytics, or VeilRead data-collection server. The current in-extension interface is primarily Simplified Chinese.

Privacy policy: https://935039168.github.io/VeilRead/privacy/en/
