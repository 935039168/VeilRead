# Chrome Web Store Listing (English)

## Name

VeilRead

## Short description

A lightweight, customizable, privacy-conscious reader for web pages and novels.

## Single purpose

Present local text or web content selected by the user in a customizable reading layer.

## Detailed description

VeilRead helps you read long-form text without leaving the current page and can import local TXT files. It offers a floating reader, edge panel, and the browser's native side panel, with page extraction, user-triggered same-site chapter navigation, catalogs, local progress, typography, opacity, and color themes.

Books, settings, site rules, and reading progress stay in the browser. VeilRead provides no cloud sync, operates no data-collection server, and contains no advertising, telemetry, or third-party analytics. The current in-extension interface is primarily Simplified Chinese.
