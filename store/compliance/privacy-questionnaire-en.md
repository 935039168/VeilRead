# Privacy Questionnaire Suggested Answers (English)

- Single purpose: present local text or web content selected by the user in a customizable reading layer.
- Collection or sale: VeilRead does not sell data and does not use data for advertising, credit, or lending purposes.
- Page content: parsed and displayed on-device for a user-visible feature; never transmitted to a VeilRead server.
- Local data: TXT books, library metadata, settings, site rules, and reading progress remain in browser storage.
- Network requests: initiated only by user action and sent directly to the selected target website; they do not pass through a VeilRead server.
- Analytics and tracking: no advertising, telemetry, third-party analytics, or cross-site tracking.
