# VeilRead 审查问题修复设计

## 目标

消除在线书进度、侧边栏模式与快捷键可靠性的关键缺陷；降低在线抓取的隐私风险；让设置、提示、可访问性、文档和测试与真实行为一致。

## 决策

采用兼容迁移，不清除用户现有 TXT、网页书或设置。在线书使用一个稳定的 `bookUrl` 身份和独立的书级进度记录；章节 URL 继续保存章内滚动位置，但书库展示、续读、重置和删除统一以在线书身份为入口。

内容脚本建立显式 `ready` Promise。后台投递命令时，内容脚本会等待初始化完成，不再静默丢弃。在线抓取限制为同源，设置超时、响应大小上限和最新请求胜出策略；跨域章节给出可理解提示而不是携带 Cookie 自动请求。

“原生侧边栏”是需要用户手势打开的浏览器能力。因此设置页改为“偏好显示方式”，选择侧边栏时给出明确入口；popup 负责调用原生侧边栏 API，网页层不会伪装为侧边栏。

## 数据与接口

- `vr.webBooks`：按稳定 `bookUrl` 保存 `{ lastChapter, title, updatedAt }`；用于进度展示、重置、删除与续读。
- `vr.webProgress`：仍按章节 URL 保存 `{ title, ratio, ts }`，用于同章节恢复。
- 设置写入走进程内串行队列，避免读改写竞争；进度写入使用同一队列。
- `reader.openWeb` 只在书身份变化时清空目录缓存；一次翻章不清缓存。
- 在线加载使用递增请求 token；旧请求完成后不再改写界面。

## UI 与可访问性

- 侧边栏模式卡片明确说明“通过插件按钮打开”。
- 所有设置标签和输入控件建立 `for/id` 关联；图标按钮补齐 `aria-label`；焦点进入阅读器工具栏时完整显示。
- 增加目录 CSS 选择器、规则错误提示、加载失败的具体原因和跨域跳转提示。
- 鼠标离开自动隐藏的文案与实现统一为“仅悬浮触发打开时完全隐藏；收起图标适用于全部打开方式”。

## 验证

新增 Node 可运行的单元测试，覆盖设置串行合并、在线书身份/进度、规则优先级与目录缓存策略；保留现有浏览器 harness，增加真实扩展手工验收清单。
