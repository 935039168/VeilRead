# VeilRead 悬浮阅读器交互与同步设计

## 目标

将自由悬浮窗设为新安装时的默认阅读形态；让阅读器内的配色、透明度和毛玻璃操作与设置中心使用同一份按形态隔离的设置；为自由悬浮窗补上可选择的边缘吸附与鼠标移出收起能力。

## 设置模型

`display.mode` 的默认值改为 `float`。`display.float` 保留几何信息，并扩展为 `snap`（默认 `true`），表示拖动结束时可吸附到四个视口边缘，以及 `autoHide`（默认 `true`），表示鼠标移出悬浮窗后自动收起。`trigger.autoHide` 保持为贴边隐藏面板的策略；`trigger.autoHideMode` 与 `trigger.autoHideDelay` 是两类页面内窗口共用的收起方式和延时。这样用户可关闭悬浮窗的移出行为，而不改变贴边面板的现有行为。

所有阅读器快捷样式修改通过 `host.patchSettings` 写入 `display.styles[modeKey]`，由 `chrome.storage.onChanged` 将最新设置推给设置中心。阅读器绝不维护一份未落盘的独立主题状态。

## 阅读器交互

工具栏中的 `Aa` 打开样式浮层。浮层提供当前窗口形态的预设配色按钮、透明度滑块和毛玻璃开关；配色按钮写入文字及背景色，选中状态按当前色值呈现。自由悬浮窗的移动手柄在指针松开时检查其四条边与视口的距离，距离不超过 16px 即把相应坐标对齐边缘，同时写回 `display.float`。窗口仍保留原有四角任意尺寸调整。

自由悬浮窗在鼠标离开后，若 `display.float.autoHide` 和全局 `trigger.autoHide` 都开启，则按既有延时和“隐藏 / 收起为小图标”策略执行。进入窗口、小图标或样式浮层会取消计时，防止用户操作时误收起。

## 设置中心

默认模式 UI 选中“自由悬浮窗”。在“触发与隐藏”页提供一个只在默认模式为自由悬浮窗时可见的“悬浮窗行为”分组，包含边缘吸附与鼠标移出自动收起开关；说明这些开关只影响自由悬浮窗。外观卡片与配色按钮继续基于 `styleTarget` 操作；任一来源更新设置后，设置页应回填模式、外观字段和新增开关（除用户正编辑的输入框）。

## 验证

为设置合并与默认值增加 Node 单元测试。通过语法检查及现有全部单元测试；人工验收覆盖阅读器内配色实时反映到设置页、四向吸附、移出隐藏与收起图标两条路径。
