# VeilRead 手工验收清单

在 Chrome 和 Edge 各执行一次；每次修改扩展后先在扩展管理页点击“重新加载”。
## 发布包与公开资料

- 解压同一个 `dist/VeilRead-v1.0.0.zip`，分别在 Chrome 与 Edge 开发者模式加载；确认两款浏览器使用同一包且无 Manifest 错误。
- 中文浏览器环境显示中文 Manifest 简介；英文环境显示英文简介，扩展内部界面仍以简体中文为主。
- 检查产品主页、双语隐私、双语支持和权利页面可公开访问且互链正确。
- 检查 128 图标、300 Logo、双语大小宣传图和十张截图，尺寸与 `store/README.md` 一致。
- 检查 ZIP 根目录含 `manifest.json`，且不含 `.git`、`.claude`、`docs`、`site`、`store`、`test`、`tools`、`package.json`、README 或源映射。

## 基础与权限

- 在普通 HTTPS 网页打开 popup，确认“阅读此页”、紧急隐藏和侧边栏入口可用。
- 在新标签页、`chrome://` 页面和扩展页确认入口给出不支持提示且不注入。
- 检查安装权限说明包含“读取和更改所有网站数据”，设置页的隐私说明与之相符。
- 在设置页用键盘聚焦“查看隐私政策与权限说明”，确认它在新标签打开公开中文隐私政策；断网时本地 TXT、设置和阅读进度仍可用。

## 快捷键与注入回退

- 新开一个普通网页，在页面完全加载前立刻按 `Alt+V`；阅读器应在初始化完成后出现。
- 在 `chrome://extensions/shortcuts` 为 Alt+V / Alt+X / Alt+↑ / Alt+↓ 分配无冲突组合。
- `Alt+X` 后，碰边缘和悬浮小把手均不得自动打开；点击插件入口或 Alt+V 后才恢复。
- 打开 popup，确认「常用快捷键」展示 `Alt + V`、`Alt + X`、`Alt + ↑ / ↓` 与阅读器内的 `Esc`；文字说明应仅提示 Alt 组合可在浏览器快捷键页面修改。

## Popup 打开方式

- popup 的「阅读页打开方式」默认选中「自由悬浮窗」；点「贴边面板」后说明文字和选中状态立即变化。
- 打开设置中心或已经显示的阅读器后切换上述选项；设置页与阅读器应立即使用同一显示方式。
- 「阅读当前页」应按已选方式打开；「打开侧边栏」保持为独立的浏览器原生面板操作；紧急隐藏按钮应醒目且不与前两项混淆。

## 跨标签页阅读窗协调

1. 在 Chrome 和 Edge 分别打开三个已注入的普通网页 A、B、C。
2. 选择自由悬浮窗，在 A 打开小说并缩小；A、B、C 都应显示恢复圆点，但不得在 B、C 预先展开或加载完整阅读窗。
3. 在 B 点击恢复圆点；A、B、C 的圆点应全部消失，且只有 B 显示完整阅读窗。
4. 从 B 切换到 C；B 的完整阅读窗默认隐藏，C 不应自动展开正文。
5. 切换到贴边面板；所有自由悬浮圆点应清除。通过边缘触发打开后，鼠标移出按设置完全隐藏，不得变成自由悬浮圆点。
6. 切换到浏览器原生侧边栏；网页边缘和小把手不得生成任何页面阅读层，“打开侧边栏”按钮仍应工作。
7. 在拥有完整阅读窗的标签页导航到新页面；旧窗体不得在新文档自动弹出，新文档仍按当前选择的打开方式响应主动操作。
8. 自由悬浮圆点已同步时，关闭 service worker 的开发者工具，保持扩展和页面不重载，等待至少 30 秒，直到扩展管理页显示 service worker（inactive）；随后在已注入页面触发一次扩展操作将其唤醒。圆点应从 `chrome.storage.session` 恢复，但不得自动展开完整阅读窗。
9. 关闭一个已注册标签页，并同时保留一个浏览器内部页；其余普通网页仍应同步，内部页不得注入或报错。

## 在线书

- 在设置中心「书库管理」添加在线书：分别填写书名、起始章节链接、目录/书籍链接；留空书名后应以网站域名显示，目录链接留空时应使用起始章节链接。
- 检查书库中每本书的操作区：不得显示“打开”，本地书仍有“重命名 / 重置进度 / 删除”，在线书仍有“编辑关键信息 / 重置进度 / 删除”；导入 TXT 和添加在线书仍可用。阅读或续读应从 popup、网页阅读层或原生侧边栏进入。
- 填写 `file:`、`javascript:` 或无效 URL；表单应明确提示不支持或链接无效，且不创建书库记录。
- 展开已添加在线书的「编辑关键信息」：改书名和起始章节后应从新章节开始且保留同书其他进度；改目录/书籍链接时应要求确认，确认后旧书记录与进度应被清除。
- 在 A 网站普通网页的 popup 或原生侧边栏中打开 B 网站在线书；当前页应保留，新标签应进入 B 网站并自动显示阅读层。不得再显示“请确认已联网且在普通网页上”的笼统错误。
- 在目标网站的普通网页打开同站在线书；应保持当前标签页，不额外创建标签页。
- 让同站章节返回 HTTP 错误、超时或无法识别正文；popup、原生侧边栏或目标阅读层应显示具体失败原因。
- 在同源的两章页面间使用上一章/下一章；快速连点后最终页面必须是最后一次操作的目标。
- 打开目录、跳转章节、再打开目录；目录不应重复网络加载或丢失。
- 让“下一章”指向另一个域名；应显示“只能自动加载同一网站”的提示，且不请求该链接。
- 在线书离开后重新打开：应回到最后章节和章内位置；书库应显示该最后章节的进度。
- 在书库重置和删除在线书：重新打开不应恢复旧章节位置。
- 让 IndexedDB 书库记录停在旧章节、但本地在线书记录指向新章节；从 popup、网页阅读层和原生侧边栏打开时，均应优先恢复新章节。
- 打开含数百至数千章节的目录页；目录加载期间页面不应出现与章节数成比例的明显卡顿。

## 侧边栏与可访问性

- 设置页选择“浏览器原生侧边栏”后，点“在当前标签页打开侧边栏”；浏览器侧边栏应出现。
- 原生侧边栏打开长章节后，滚轮只滚动正文区域，顶部书籍选择条保持可见。
- 使用 Tab 键浏览 popup、设置页、侧边栏和阅读器工具栏；所有可操作控件应有可见焦点。
- 点击设置项的文字标签，应能聚焦或切换其对应控件。

## 数据与视觉

- 同时在两个普通网页调整不同设置，最后保存的设置应同时包含两次改动。
- TXT 导入、续读、删除、GBK/UTF-8 解码和目录跳转均应维持原有行为。
- 新安装/清空 `vr.settings` 后，默认打开方式应为“自由悬浮窗”；已有用户保存的显示方式不应被重置。
- 在悬浮窗中点 `Aa`，选择任一配色、调整透明度或毛玻璃；设置页已打开时应实时回填同一悬浮窗外观，并标出当前配色。
- 自由悬浮窗选择“冷灰”后，正文面板、目录和 `Aa` 浮层均为冷灰背景；透明度和毛玻璃仍沿用该形态原有设置。
- 阅读器隐藏时拖动浏览器窗口任意边框调整尺寸；停在触发边缘不得打开。鼠标先离开再重新进入热区后，仍应按延迟正常打开。
- 在设置页把光标停在站点规则输入框，再从阅读器修改配色、字号或行距；阅读外观区域仍应实时回填。编辑阅读外观自身的输入框时，不应被外部更新打断。
- 勾选“拖动到边缘时自动吸附”后，拖到上/下/左/右边缘约 16px 内应贴齐；取消勾选后位置保持自由。
- 拖动悬浮窗后立即在 `Aa` 中选择“重置悬浮窗位置与大小”；等待至少 300ms 后，位置和尺寸不得被先前拖动的旧值覆盖。
- 关闭“自由悬浮窗：鼠标移出后自动收起”后，移出不应影响悬浮窗；开启后，未吸附的悬浮窗应收起为其右下角的恢复圆点，点击后恢复。
- 开启贴边面板自动收起后，分别通过碰边、快捷键和 popup 打开面板；鼠标移出后都应完全隐藏，不能变成自由悬浮圆点。延时期间重新打开或进入面板，旧的隐藏任务必须取消。
- 分别把悬浮窗吸附到右、左、上、下边缘；移出后恢复圆点应停在对应边缘。位于角落时，顺序应优先右、再左、再上、最后下。
- 收起自由悬浮窗后，拖动恢复圆点到任意可见位置并松开；再次收起或重新打开浏览器后，圆点应仍停在该位置。移动不超过 4px 时应视作点击并直接恢复。
- 拖动恢复圆点后，记录它到浏览器右边和下边的间距；先缩小、再放大浏览器窗口，空间足够时这两个间距应保持不变。
- 拖动或缩放已设置圆点位置的悬浮窗后再次收起；圆点不应沿用手动坐标，而应重新跟随窗口（已吸附时跟随对应边缘，未吸附时在窗口右下角）。
- 悬浮窗、四向贴边、透明度、毛玻璃、自动隐藏和自由悬浮恢复圆点应按设置工作。
- 在贴边面板与原生侧边栏打开 `Aa`；提示不得出现悬浮窗拖拽或重置悬浮窗操作。
