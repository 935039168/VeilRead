VeilRead

显示方式

选好后，鼠标碰到屏幕对应边缘，阅读面板就从那一侧滑出。

左右贴边时是面板的宽度，上下贴边时是高度。也可以在阅读时直接用鼠标拖动面板内侧的边缘来调整。

拖动悬浮窗时，距离屏幕任一边缘约 16px 内会自动贴齐；继续拖动即可离开边缘。

仅影响自由悬浮窗。移出后会收起为一个恢复圆点：吸附时圆点贴在吸附边，未吸附时位于窗口右下角；等待时间在“呼出与隐藏”中设置。

限制每行最多显示多宽的文字。行太长时眼睛容易串行，设一个舒适宽度（比如 600）阅读更轻松。0 表示不限，撑满整个阅读窗口。

中文小说习惯：每个段落开头缩进两个字的位置。去掉勾选则顶格显示。

为了在你打开的普通网页上提供边缘呼出和正文提取，VeilRead 需要访问 HTTP/HTTPS 网页。它不会向 VeilRead 的服务器上传内容或阅读记录；在线翻章仅会向你正在阅读的同一网站请求章节。

阅读外观

三种窗口形态的配色、透明度、毛玻璃效果互不影响，可以分别设置。切换上面的选项后再调整下方设置即可。字体、字号、行距为三种形态共用。

预设的几种常见组合：白天阅读推荐「纯白」「米黄」，夜间推荐「暗夜」「纯黑」。

文字的大小。也可以在阅读时点底部的「Aa」按钮快速调整。

行与行之间的距离。数值越大行越稀疏，长文阅读 1.8 左右比较舒适。

想完全自定义时直接取色。配色方案一栏点选会同时覆盖这两项。

调低后可以透过阅读窗口隐约看到后面的网页。阅读时把鼠标放在窗口上按住 Ctrl 转动滚轮，也能随时调整（只影响当前窗口形态）。

窗口半透明时，把背后被透出来的内容做模糊处理：开启＝磨砂玻璃质感（推荐，文字更清楚）；关闭＝纯粹透明，看得清背后原样。

第一章 风起

旧历三百年秋，北境第一场雪比往年来得早了半个月。守夜人在城墙上呵出白气，看见远处山道上有一点灯火缓缓靠近。

"来了。"他说。

没有人回答他。所有人都在看着那点灯火，仿佛它是什么了不得的东西——事实上也确实如此。

呼出与隐藏

开启后，阅读窗平时"藏"在屏幕边缘：把鼠标移到下面指定的边缘，阅读窗自动出现，不需要点击。

鼠标需要碰到屏幕边缘多宽的一条区域才算触发。太薄不好碰到，太厚容易误触发。

鼠标在边缘停留这么久才打开阅读窗。调大一点可以避免鼠标路过时误触发。

开启后，鼠标移开任何已打开的贴边面板一段时间，它就按下面选择的方式收起来。自由悬浮窗请在“显示方式”中单独设置。

完全隐藏：贴边面板在鼠标移出后消失。小图标：贴边面板缩成一个小圆点留在原地；自由悬浮窗移出时始终使用恢复圆点，点一下立即恢复。

鼠标离开后等待这么久才收起，避免只是鼠标划过就消失。

在页面边缘常驻一个半透明的小竖条：鼠标悬浮上去打开阅读窗，点一下则常开/收起。给不喜欢"碰边缘"这种隐形触发方式的用户一个看得见摸得着的入口。

0% 是屏幕最上方，100% 是最下方，默认在中间。

快捷键与手势

Alt + V显示 / 隐藏阅读器
Alt + X紧急隐藏：屏幕上瞬间清空一切痕迹，且悬浮触发同时失效，直到你主动再次打开（快捷键或点击入口）
Alt + ↓下一章（在线小说也会自动抓取下一章内容）
Alt + ↑上一章
Esc阅读窗显示时：立即隐藏
← / →鼠标放在阅读窗上时：上一章 / 下一章
PgUp / PgDn / 空格鼠标放在阅读窗上时：向上 / 向下翻页
Ctrl + 滚轮鼠标放在阅读窗上时：快速调节透明度
拖动窗口悬浮窗：拖顶部条移动位置，拖任意一个角调整大小（大小不设上限）
拖动边缘贴边面板：拖内侧边缘直接调整宽度/高度

以上快捷键仅在普通网页上生效；浏览器的新标签页、设置页等内部页面无法使用。

站点规则

内置算法能自动识别大多数小说站和普通网页的正文。如果某个网站识别得不好（正文缺一段、或者把广告当成正文）， 可以在这里为它手写规则。所有空格内填的都是「CSS 选择器」——最简单的获取方法：在网页上对着正文区域 右键 → 检查，找到包裹正文的元素，把它的 id（如 #content）或 class（如 .novel-text）填进来。

书库管理

支持 UTF-8、GBK、Big5 编码，自动按「第一章 / 第1章 / 楔子 / 番外」等切分章节，并在导入后自动开始阅读。

起始章节决定从哪里开始阅读；目录 / 书籍链接用于识别同一本书，可与章节链接不同。链接仅支持 HTTP(S)。
