Support and FAQ

The reader does not open on a page

Browsers do not allow content scripts on internal pages, new-tab pages, or extension management pages. Use VeilRead on an ordinary HTTP or HTTPS page.

Page extraction is incomplete

Add site-specific CSS selectors for content, title, chapter navigation, and catalog in Settings.

Report an issue

Open a ticket in GitHub Issues with your browser version, reproduction steps, and a screenshot containing no personal data.
